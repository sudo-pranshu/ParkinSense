## 5. What a reader can now do from this branch alone

Understand the project and its validation status (README, index); set up hardware and software
(installation, hardware); build and flash firmware (firmware — v4 verified, v5 pending H0);
decode the protocol byte by byte (protocol); run and record (runtime); understand every
algorithm with its equations and parameters (algorithms); replay and build leakage-safe datasets
(datasets); reproduce the benchmarks (testing); extend the system safely (contributing, ADRs); and
see exactly what is and is not validated (biomarkers, results, hardware procedure).
